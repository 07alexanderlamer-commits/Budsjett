# Budsjett

Personlig budsjett + bedriftsregnskap for Lamer Mobil, som nettside-app (PWA).

- **Frontend:** React + Vite, publiseres automatisk til GitHub Pages ved hver push til `main`.
- **Data og innlogging:** Supabase. Alle tabeller har Row Level Security, så hver bruker ser bare sine egne data.
- **Databaseoppsett:** `supabase/oppsett.sql`

Lokal utvikling: `npm install` og `npm run dev`.
